# WorthIt

WorthIt is a UK resale-value checker for used electronics.

## First version

This MVP focuses on **Identify → Configure → Value → Compare → List** with seeded market data. It is intentionally structured so real comparable-sale data can replace the demo dataset later.

> Prices shown in this first version are illustrative demo market data, not live marketplace quotes.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.
